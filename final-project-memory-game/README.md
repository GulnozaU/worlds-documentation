# Final Project - Memory Matching Game

This folder contains a text-based C++ Memory Matching Game and the assignment submission materials.

## Files

- `memory_matching_game.cpp` - main C++ source code
- `animals_theme.txt` - 50 animal theme words
- `space_theme.txt` - 50 space theme words
- `sports_theme.txt` - 50 sports theme words
- `assignment_submission.md` - readable assignment write-up
- `WeekFinalFirstNameLastNameMemoryMatchingGame.docx` - Word-compatible assignment write-up
- `test_4x4_output.txt` - successful 4x4 test run transcript
- `test_6x6_output.txt` - successful 6x6 test run transcript
- `test_8x8_output.txt` - successful 8x8 test run transcript

## Compile

```bash
g++ -std=c++17 -Wall -Wextra -pedantic memory_matching_game.cpp -o memory_matching_game
```

## Run

```bash
./memory_matching_game
```

Before submitting, replace `Student Name` / `First Name Last Name` with your real name in the source code and write-up.
